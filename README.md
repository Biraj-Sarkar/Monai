## 1. Introduction
Monai is an expense tracker application with AI-powered insights designed to help users record spending, review trends, and make better financial decisions.

## 2. Features
- Expense tracking and management
- AI insights for monthly spending analysis
- Category-wise breakdowns and trends
- Budget planning support
- Responsive user interface with light and dark themes

## 3. Installation
1. Clone the repository.
2. Install dependencies for the frontend and backend.
3. Configure environment variables.
4. Start the backend server.
5. Start the frontend development server.
